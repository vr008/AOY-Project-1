Graph Algorithms Experiment Results
===================================

1. INTRODUCTION

This project implements three graph algorithms in C++: connected
components using DFS, cycle detection using DFS, and shortest paths
using Dijkstra's algorithm.

The graph type selected for this assignment is UNDIRECTED.

2. SIMULATED TESTING

Four graph types were tested: cycle, complete, empty, and heap.
Each type was tested with different numbers of vertices.

3. SIMULATION OBSERVATIONS

The complete graphs use more memory because they have many more edges.
The empty graphs use very little memory. The cycle graph shows a large
increase in shortest-path time as the number of vertices increases.

7. REAL-WORLD OBSERVATIONS

The real-world graph is much larger than the simulated graphs, so it
requires much more memory. The shortest-path function uses the most
memory because it stores a complete path for every reachable vertex.

Cycle detection uses an explicit DFS stack instead of recursive DFS.
This makes the implementation safer for a graph with more than one
million vertices.

8. CONCLUSION

The required graph algorithms were implemented and tested on four
different simulated graph types. The real-world bonus graph also
completed successfully, and all three adjacency criteria were actually
tested.

9. HOW TO RUN

The project was tested on Linux using g++.

To run all simulated graph tests:

chmod +x run_all_tests.sh
./run_all_tests.sh

This script compiles the C++ files and runs the cycle, complete, empty,
and heap graph experiments. The results are saved in results.txt.

To run the real-world bonus test:

chmod +x run_realgraph_make.sh
./run_realgraph_make.sh

This script compiles realgraph_make.cpp, loads roadNet-PA.txt, runs the
real-world graph tests, and saves the results in real_results.txt.

The main simulated program can also be run manually:

g++ -std=c++17 graph_operations.cpp graph_simulator.cpp simulated_test.cpp -o graph_test

./graph_test cycle 1000
./graph_test complete 1000
./graph_test empty 1000
./graph_test heap 1000

For the real-world graph, roadNet-PA.txt must be in the same folder as
realgraph_make.cpp and run_realgraph_make.sh.
