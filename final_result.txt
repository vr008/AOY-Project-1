Graph Algorithms Experiment Results
===================================

1. INTRODUCTION

In this project, I implemented and tested three graph algorithms in C++.
I used DFS for finding connected components and detecting cycles, and I
used Dijkstra's algorithm for finding shortest paths.

For this assignment, I used an UNDIRECTED graph.

2. SIMULATED TESTING

I tested four different types of graphs: cycle, complete, empty, and heap.
I also tested different numbers of vertices for each graph type.

3. SIMULATION OBSERVATIONS

From the tests, I noticed that the complete graphs used the most memory
because they have a lot more edges. The empty graphs used very little
memory. I also noticed that the shortest-path time increased a lot as the
number of vertices increased, especially for the larger cycle graphs.

7. REAL-WORLD OBSERVATIONS

The real-world graph is much bigger than the simulated graphs, so it
needed much more memory. The shortest-path function also used a lot of
memory because it stores a complete path for every reachable vertex.

For the large graph, I used an explicit DFS stack for cycle detection
instead of recursive DFS. This makes it safer to run on a graph with more
than one million vertices.

8. CONCLUSION

Overall, I implemented the three required graph algorithms and tested them
on four different graph types. I also tested the RoadNet-PA graph for the
bonus part. In addition, I tested all three adjacency criteria.

9. HOW TO RUN

The project was tested on Linux using g++.

To run all simulated graph tests:

chmod +x run_all_tests.sh
./run_all_tests.sh

This script compiles the C++ files and runs the cycle, complete, empty,
and heap graph tests. The results are saved in results.txt.

To run the real-world bonus test:

chmod +x run_realgraph_make.sh
./run_realgraph_make.sh

This script compiles realgraph_make.cpp, loads roadNet-PA.txt, runs the
real-world tests, and saves the results in real_results.txt.

The main simulated program can also be run manually:

g++ -std=c++17 graph_operations.cpp graph_simulator.cpp simulated_test.cpp -o graph_test

./graph_test cycle 1000
./graph_test complete 1000
./graph_test empty 1000
./graph_test heap 1000

For the real-world graph, roadNet-PA.txt must be in the same folder as
realgraph_make.cpp and run_realgraph_make.sh.
